# Machine Learning Projects

A collection of Machine Learning projects implemented using **Python**, covering both **Regression** and **Classification**.

## 📌 Projects

### 1. 🏠 House Price Prediction

Predicts house prices using **Linear Regression** and **OLS Regression**.

**Techniques:**

* Simple Linear Regression
* Multiple Linear Regression
* OLS Regression
* Data Visualization
* Model Evaluation

**Features used:**

* RM
* LSTAT
* PTRATIO

**Best R² Score:** `0.679`

---

### 2. 📞 Telco Customer Churn Prediction

Predicts whether a telecom customer is likely to **churn** using Logistic Regression.

**Techniques:**

* Data Preprocessing
* Exploratory Data Analysis
* Logistic Regression
* Classification
* Model Evaluation

**Goal:** Identify customers who are likely to leave the service.

## 🚀 How to Run

### Clone the repository

```bash
git clone https://github.com/KishanHP1808/ML-project.git
cd ML-project
```

### Install dependencies

```bash
pip install pandas numpy matplotlib seaborn scikit-learn statsmodels jupyter
```

### Run

```bash
jupyter notebook
```

Open the required `.ipynb` file and run the cells.
